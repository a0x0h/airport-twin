# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep criticism about the work, not the person. Harassment, insults and personal attacks are not tolerated in issues, pull requests or any other project space.

## Reporting

If you see or experience unacceptable behaviour, contact the maintainer through a [private security advisory](https://github.com/a0x0h/airport-twin/security/advisories/new) or the email on the maintainer's GitHub profile. Reports are handled confidentially.

Maintainers may remove comments, commits or contributions that break this code, and may ban contributors who repeatedly do so.
